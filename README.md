<h1 align="center"> SBA 308A <h1>

This program utilizes the <a href="https://www.openbrewerydb.org/">Open Brewery DB</a>. It has a navigation bar for decoration purposes. Under the nav bar is an input. You can put in any city and search through the database. It outputs the data, displaying ten different breweries within the chosen city with some information about the brewery.

<h3 align="center"> Issues </h3>

Assignment had a requirement to use the POST method. The API used only gives permissions for the GET method. No information can be written to the API.
